## The line

> The bug that takes a week to find will be fixed by deleting one line you swore was essential.

One original fortune-cookie line for a software developer (93 characters, one line, no newline inside).

## How it works

`main.ts` (Node 22, stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, refusing to run if the line ever exceeds 120 characters or contains a newline.
